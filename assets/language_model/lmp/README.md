# Lmp assets

Language-model data for character and word-location evidence. Compressed tables are
grouped by direction and n-gram order; the lmp index describes their organisation.
Select orders through scoring configuration and install the matching asset profile when
a run needs larger models.

Subfolders: [char/](char/), [ecdf/](ecdf/), [wli/](wli/).

See [installation and asset profiles](../../../docs/setup/installation.md).

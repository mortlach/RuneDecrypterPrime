# Ecdf assets

Calibration data for character and word-location scoring. The NPZ filenames distinguish
direction, n-gram order, window and statistic. Calibration must match the model and
configured objective; these files are not interchangeable alternative plaintexts.

Subfolders: [char/](char/), [wli/](wli/).

See [installation and asset profiles](../../../../docs/setup/installation.md).

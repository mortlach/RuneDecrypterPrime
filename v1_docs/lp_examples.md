# Liber Primus examples

Status: retained redirect and boundary note

Liber Primus is the main real puzzle domain that shaped RDP, but not every
workbook belongs in the first route.

- `tutorials/v1/getting_started/07_liber_primus_source.py` loads named source
  data and explicitly does not claim a solve.
- `tutorials/v1/examples/lp_welcome_pilgrim_solve.py` bridges to the reviewed
  Welcome Pilgrim workbook.
- `solving/solved_lp/` contains the detailed solved workbooks.
- `src/rdp/data/liber_primus/` owns source labels, locators and partitions.

The complete runnable entry, asset and truth-use details live in
`tutorials/v1/README.md`.

# Migration notes — v0.5

This slice tightens the control layer rather than promoting another large set of
old documents.

## What this adds

1. a canonical update/logging format file
2. reusable planning templates for future agent work
3. a cross-project dependency map
4. a problem-thread index
5. a fuller migration ledger that records the first five slices

## Why this slice matters

The bundle now has real homes for:
- active projects
- completed material
- legacy material
- archive material

What it still needed was a cleaner operating system for future updates:
- how to write new files consistently
- how to track dependencies between projects
- how to co-ordinate named problem threads across the work

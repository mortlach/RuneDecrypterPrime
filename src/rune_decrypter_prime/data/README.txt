rune_decrypter_prime/data
=========================

Static assets bundled with the project.

Contents
--------
- `language_model/`: character and WLI n‑gram tables plus ECDF caches used by
  `LmPrimeRuntime`. Subfolders mirror direction (`ltr`/`rtl`) and channel.
- `cipher_tests/`: plaintexts, word-break indices, and helper fixtures used by
  Tier‑A tests/tutorials.
- `liber_primus`, `tutorials`, etc.: curated datasets for tutorials.

Guidelines
----------
- Treat this directory as read-only at runtime. Scorers load tables from here,
  but anything generated by a run must go under `output/`.
- When updating the language model, keep the folder layout stable so older
  code (and the optional `_fastlm` extension) can keep streaming data without
  path rewrites.

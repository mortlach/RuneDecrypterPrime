# Tags and statuses

Use a small fixed vocabulary.

## Document status

- `canonical`
- `active`
- `parked`
- `legacy`
- `completed`
- `archive`
- `superseded`
- `unclear`

## Work status

- `done`
- `in_progress`
- `not_started`
- `blocked`
- `needs_review`
- `wtf`

## Suggested header block

Use this near the top of active planning documents.

```text
Status: active
Work status: in_progress
Project: rdp_v1
Owner: owner-review / maintainer
Last updated: YYYY-MM-DD
Source-of-truth parents:
- ...
```

## Use of `wtf`

`wtf` is allowed as a temporary triage status for:
- unclear ownership
- conflicting documents
- unclear whether still relevant
- mixed legacy/live material not yet sorted

Do not leave a document in `wtf` forever.

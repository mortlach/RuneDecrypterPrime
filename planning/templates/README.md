# Planning templates

These templates exist to make later migration and project updates consistent.

Use them as starting points.
Do not copy them blindly when a shorter note would do.

## Templates included

- `project_current_state_template.md`
- `workstream_index_template.md`
- `active_runbook_template.md`
- `project_snapshot_template.md`
- `problem_brief_template.md`
- `result_note_template.md`
- `status_ledger_template.csv`

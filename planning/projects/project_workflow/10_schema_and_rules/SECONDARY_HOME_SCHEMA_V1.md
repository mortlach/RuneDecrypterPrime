# Secondary-home schema v1

Status: active
Work status: done
Project: project_workflow

## Completed homes

Completed homes should usually use a lighter shape:

- `00_SUMMARY.md`
- `01_DOCUMENT_MAP.md`
- `02_KEY_EVIDENCE.md`
- optional reference subfolder

## Archive homes

Archive homes should usually use:

- `00_ARCHIVE_NOTE.md`
- `01_DOCUMENT_MAP.md`
- `source_pack/`

## Legacy homes

Legacy homes should stay thin and clearly non-authoritative:
- one note explaining what they preserve
- links to the newer live homes if relevant

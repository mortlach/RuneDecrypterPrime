# Active project front-door template

Use this small front-door set for active projects:

- `00_CURRENT_STATE.md`
- `01_WORKSTREAM_INDEX.md`
- `02_PROJECT_DEFINITION_AND_AGENT_RULES.md`
- `03_DOCUMENT_MAP.md`
- `04_ACTIVE_RUNBOOK.md`
- `05_REMAINING_WORK.md`

## Goal

A new reader should be able to understand:
- what this project is
- what is active now
- what to read next
- what is still open

without first reading legacy/reference packs.

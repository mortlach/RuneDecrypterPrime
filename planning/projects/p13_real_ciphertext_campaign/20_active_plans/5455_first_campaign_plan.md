## Immediate objective

Create the smallest controlled planning pack for the `5455` thread without
mixing it into the broader benchmark campaign.

## First safe steps

### Step 1. Keep the source surface explicit
Use these anchors:
- `5455_problem_brief.md`
- solve-proof source docs
- LP transcript/API evidence snapshots
- upstream no-WLI planning links

### Step 2. Create one compact status ledger
Fields should probably be:
- date
- problem thread
- current best evidence
- blocker
- next intended run or question
- linked evidence files

### Step 3. Define the first exact question
The first question should be narrow.
Examples:
- what exact payload/source route is canonical for the `5455` thread?
- which upstream no-WLI findings are already strong enough to justify transfer?
- what first benchmark/control comparison should accompany any real-ciphertext attempt?

### Step 4. Avoid premature bulk migration
Do not pull every historical p13 note into this home yet.
Only move material once it clearly belongs to the live `5455` thread.

## Non-goals for this slice

- not a giant p13 archive
- not a complete solve strategy writeup
- not a claim that real-ciphertext campaign evidence is already mature

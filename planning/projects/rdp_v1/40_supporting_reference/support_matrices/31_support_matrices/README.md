# Support matrices and mapping notes

This folder preserves a small set of `rdp_v1` support materials that help with
convergence work, but are not themselves the main entry point.

## Included in this folder

### Support matrices / code-mapping notes
- feature support matrix draft
- method-family and capability workbook
- current-code mapping template
- old current-code mapping note
- support-to-test map
- support-matrix cell meanings
- findings register

### Workflow / planning support notes
- change workflow note
- effort-bands note
- older implementation-plan text notes

## Working rule

Use these as support reference when tightening `rdp_v1`.
Do not let them replace the main:
- current state
- workstream index
- active runbook
- current code-crosscheck note

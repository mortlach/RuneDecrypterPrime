10. What this mapping now makes clear

This filled mapping note sharpens five important points.

10.1 The repo already has real outer and inner campaign layers

That distinction is not theoretical.
It is physically present in the code.

So any implementation plan that talks about “campaigns” as one single blob is too vague.

10.2 RunSpec convergence is a real convergence task, not a blank-slate design

Today’s public-ish surface is:

RunAPI

CipherSpec

KeySpec

SolverSpec

normalisers

RunConfig

The job is to converge these honestly, not invent an abstract replacement detached from present usage.

10.3 Reporting is half converged, not fully converged

ScorerReport is real.
SolverReport still needs a real landing.
Runner-local projection logic still exists.

10.4 Output/privacy is one of the least converged cross-cutting areas

The docs are right to treat it as an early workstream.

10.5 LP/data is comparatively strong and should be treated as a parity anchor

The LP/domain and asset path surface is already more first-class than some other areas.
That makes it useful as a stabilising anchor during the refactor, not as a secondary cleanup concern.

# Migration notes — v0.7

This slice does one substantial benchmark-side migration and one honest
p13-source check note.

## What this adds

1. the older `rdp_community_benchmark_v1_1_spec` bundle is folded under the
   `benchmark_campaign_v1_1` project home as a reference pack
2. the p13 real-ciphertext home gets a source-search note recording what old
   planning material was and was not actually found for `5455` / p13

## Why this slice matters

The benchmark project now absorbs one of the older but still relevant support
clusters instead of only pointing at it.

The p13 real-ciphertext project also becomes more honest:
it now says plainly that no clearly named old `5455` planning doc was found in
the planning tree, only broader p13-readiness material.

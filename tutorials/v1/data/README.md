# Example inputs

This folder holds messages and setup data shared by the worked examples.
`plaintext_fixtures.py` supplies constructed messages, and
`two_period_cribs_demo.py` prepares the two-period inputs.
`periodic_columnar_p7_warm_start.py` supplies the existing P7 warm-start setup.

The getting-started files keep their small inputs in the file itself, so you
can see the whole problem together. Larger examples reuse data from here.
If an example uses a crib or initial key, explain where it came from and how
it helps the search.

Choose a run from the [example catalogue](../README.md).

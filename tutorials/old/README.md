# Old Tutorial Files

This folder keeps replaced or blocked tutorial files out of the public V1
tutorial set.

Current public V1 tutorials live in:

```text
tutorials/v1/
```

Old files here are retained for reference only. They are not selected by the V1
pretty-print release runner.

## Folders

| Folder | Meaning |
| --- | --- |
| `v1_replaced_by_pretty_print/` | Older tutorial versions replaced by the current V1 pretty-print tutorials. |
| `v1_blocked/` | Older tutorials with known blocking issues or superseded entrypoints. |

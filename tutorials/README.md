# Tutorials and examples

Start with [`v1/getting_started/`](v1/getting_started/) for a short route through
RDP's usual calls. Use the [example catalogue](v1/README.md) when you want to
try a particular cipher or search method.

From the repository root, run the default selection with:

```text
python tutorials/v1/run_tutorials.py
```

The numbered files use the installed public API. Some worked examples also
use repository helpers to prepare their inputs and reports; the catalogue
points these out.

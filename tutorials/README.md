# Runnable material

- Start with [`v1/getting_started/`](v1/getting_started/).
- Use [`v1/README.md`](v1/README.md) for the complete example catalogue.
- Run the normal bounded selection with `python tutorials/v1/run_tutorials.py`.

The numbered route uses only the installed public API. Retained examples may
use repository support when their stated purpose requires it; the catalogue
makes that boundary visible.

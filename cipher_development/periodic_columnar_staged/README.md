# Periodic-columnar decomposed qualification

This specialist cipher-development workflow qualifies a P7/C7
columnar-then-substitution solve using one fixed, deterministic recipe:

```text
char1/2 structured head generation
    -> retain the single best score-selected head
    -> enumerate all 5,040 C7 tails for that head
    -> char3/4 shortlist and WLI2/4 ranking
    -> retain the single best complete key
    -> one-start char3/4 Kaeding refinement through api.run
    -> terminal exact-plaintext evaluation
```

The exhaustive tail step is a bounded structural enumeration, not an open-ended
search. Candidate construction and static scoring use the exact internal modules
that own those development capabilities. The integrated solve uses the public
`CipherSpec`, `KeySpec`, `ScoringConfig`, `SolverSpec`, `RunSpec` and `api.run`
surface. The qualification deliberately hands one seed to one solver restart.
This is the same deterministic seed that occupied restart zero in the recorded
successful development run; it is regenerated by scoring, not hard-coded or
selected with benchmark truth.

Search configuration and candidate evidence contain no benchmark plaintext,
known key, match ratio or oracle fields. Benchmark truth is evaluated only after
the single solver run has completed. A completed process is promoted only for
exact plaintext recovery; exact recovery of unused key-table entries is not
required.

## Modes

- `smoke`: P1/C2 contract preflight using the same candidate-reduction and
  public-solver path. It passes on coherent completion and records recovery
  diagnostically; only the P7/C7 qualification claims an exact solve.
- `qualification`: P7/C7, 2,489 runes, full assets and a 60-minute wall-clock
  limit.

## V2 reduction

The v2 follow-up replaces the v1 four-head/eight-key handoff with one retained
head, one WLI-ranked key and one restart. It also preserves candidate selection
per head instead of applying a second global re-ranking step. This is the
minimal passing recipe to qualify before any further runtime reduction.

Set the constants in `cipher_development/run_experiment.py` to experiment
`periodic_columnar_staged`, mode `development` and seed `12345`, then use the
single development entry point:

```text
python -X utf8 cipher_development/run_experiment.py
```

The entry point resolves the repository from its own location, fixes the
working directory for Git provenance, mirrors stdout and stderr to the visible
terminal, and writes a timestamped transcript under the external
`run_outputs/tests/cipher_development/` root. Candidate, progress and terminal-
evaluation artifacts are written incrementally under the external
`run_outputs/cipher_development/` root.

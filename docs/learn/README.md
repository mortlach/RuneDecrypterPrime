# Learn RDP by solving

This route is for getting a first experiment running quickly.

The [learner glossary](00_words_used_here.md) defines every technical term used
in this track. Keep it open and use it whenever a name is unfamiliar.

The examples are deliberately small. They use existing ciphers, ordinary
defaults and bundled data so each page can concentrate on one idea.

First complete the [installation](../setup/installation.md), then run these
Python examples in that environment. The named LP transcript is also included
in the wheel; larger language-model sets remain part of the full installation.

Start here:

1. [Apply a known key](01_apply_a_known_key.md)
2. [Search a key](02_search_a_key.md)
3. [Change one thing](03_change_one_thing.md)
4. [Use Liber Primus data](04_use_liber_primus.md)
5. [Read the result](05_read_the_result.md)
6. [Where to go next](06_where_next.md)

Optional explanations: [Basic solver settings](02_basic_solver_settings.md)
and [What can the score tell you?](05_scoring_limits.md).

You can stop after any page and use the pattern in your own script.

The fuller guides explain the options that are intentionally omitted here.

# Glossary

| Term | Meaning | See Also |
| --- | --- | --- |
| **KNF (Key Normal Form)** | Canonical representation of a cipher key used for validation/tests | `howto/add_cipher.md`, `tests/ciphers` |
| **WLI** | Word/Letter Incidence pairs emitted by scorers | `guides/scoring_deep.md` |
| **Patience** | Number of solver steps since last improvement (used for early stop) | `solvers/solver_base.py`, `tests/telemetry/test_progress_events.py` |
| **Budget** | Hard cap on evaluations or iterations for deterministic runs | `guides/architecture.md` |
| **Pipeline block** | Telemetry summary describing direction + input permutation | `telemetry/pipeline.py`, `guides/telemetry.md` |
| **Run directory** | `output/<kind>/<timestamp>__<label>__<git>/` folder containing META/logs/trace/artifacts | `guides/outputs.md` |

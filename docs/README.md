# Documentation

## New to RDP

Start with [Learn RDP by solving](learn/README.md).

If the basic cryptography terms are new, the learning route begins with a short
[definitions page](learn/00_words_used_here.md).

It uses short scripts and ordinary defaults to get from a known-key operation to
a small search and then to real Liber Primus data.

Use the rest of this index when you need more control or want to understand the
internals.

The main route is:

1. [Installation](setup/installation.md)
2. [Quickstart](guides/quickstart.md)
3. [Ciphertext input](guides/ciphertext_input.md)
4. [Word-length information](guides/word_length_information.md)
5. [Text direction](guides/text_direction.md)
6. [Defining a run](guides/anatomy_of_a_run.md)
7. [Comparing solve experiments](guides/working_a_solve.md)
8. [Reading a result](guides/results.md)

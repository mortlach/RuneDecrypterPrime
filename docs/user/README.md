# User route

RDP’s ordinary path is deliberately short:

1. [`Install`](../setup/installation.md).
2. [`Run the seven-stop route`](../guides/quickstart.md).
3. [`Understand runes, indices and direction`](../guides/runes_and_text.md).
4. [`Choose a worked example`](../../tutorials/v1/README.md).
5. [`Read outputs`](../guides/outputs.md) or
   [`troubleshoot`](../guides/troubleshooting.md) when needed.

Start with:

```text
python tutorials/v1/getting_started/01_known_key.py
```

The examples are independent runnable investigations and release evidence. Use
the catalogue to choose the problem shape that matches your work.

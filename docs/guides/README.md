# Using RDP

Start with `quickstart.md` and `anatomy_of_a_run.md`. `runes_and_text.md` explains the
representations; `solvers.md`, `keyops.md` and `scoring.md` explain the main choices.
`outputs.md` and `telemetry.md` help inspect results, while `troubleshooting.md`
addresses failures. The deeper and LP-specific guides support particular investigations
after the ordinary request is familiar.

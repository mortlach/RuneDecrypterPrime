# Contributor tasks

Task-focused pages explain how to extend or inspect RDP. Start at `add_cipher.md`,
`build_keyops.md` or `add_solver.md` for component development. `wrappers.md` explains
the current typed-constructor boundary despite its historical filename. These pages
target contributors; the quickstart remains the ordinary user route.

Continue with the [related guide](../guides/quickstart.md).

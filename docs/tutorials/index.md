# Runnable RDP material

The ordered route starts at
[`tutorials/v1/getting_started/01_known_key.py`](../../tutorials/v1/getting_started/01_known_key.py).
Its reading order and purpose are described in the
[`getting-started guide`](../guides/quickstart.md).

The only complete catalogue of retained runnable examples is
[`tutorials/v1/README.md`](../../tutorials/v1/README.md). It records purpose,
cipher and solver, public or repository support, asset profile, runtime class,
result policy and truth/oracle use for every example.

Run the normal release selection with:

```text
python tutorials/v1/run_tutorials.py
```

The three several-hour P7/C7 programs are available only through the explicit
`QUALIFICATION` selection. They are not part of the default or full-asset
example proof.

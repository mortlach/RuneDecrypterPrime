# Tutorials and examples

Begin with the [getting-started guide](../guides/quickstart.md). It takes you
through the numbered files, starting with
[`01_known_key.py`](../../tutorials/v1/getting_started/01_known_key.py).

The [example catalogue](../../tutorials/v1/README.md) lists all the runnable
examples. Use it to choose a problem and check its assets, approximate runtime,
expected result and use of any known answer.

Run the default selection from the repository root:

```text
python tutorials/v1/run_tutorials.py
```

The longer P7/C7 programs have their own `QUALIFICATION` selection. The default
and full-asset example groups leave them out.

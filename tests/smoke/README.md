# Smoke tests

Selected end-to-end checks for solver, determinism and CUDA paths. The folder name is
not a promise that every test is cheap or supported on every machine.

Useful entry points: [test_cuda_solver.py](test_cuda_solver.py), [test_determinism_canary.py](test_determinism_canary.py), [test_kaeding_public_api_smoke.py](test_kaeding_public_api_smoke.py).

See [test selection and tiers](../../docs/tests_docs/tiering.md) for the wider testing context.

# Robustness campaigns

`cipher_solver_campaign.py` runs the campaign described by
`cipher_solver_campaign_config.py`. `fixtures/` provides repeatable inputs. Campaigns
compare behaviour across recipes and seeds; they can be expensive and are not part of
ordinary onboarding. P7/C7 follow-up remains explicit roadmap work.

Continue with the [related guide](../../docs/ROADMAP.md).

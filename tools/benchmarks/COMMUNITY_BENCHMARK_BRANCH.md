# Community Benchmark Branch Guide

This branch is intended for reproducible benchmark runs by external contributors.

## Goals
- Keep benchmark config explicit in source files (no runtime env var toggles).
- Keep outputs comparable across machines via stable run profiles + config fingerprinting.
- Make solved-instance autoskip the default.

## 1) Setup
```powershell
git clone <repo-url>
cd RuneDecrypterPrime
git checkout benchmark-community

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
python -m pip install -e .[dev]
```

## 2) Primary benchmark scripts
- `tools/benchmarks/bench_solve_periodic_columnar_pipeline.py` (`order=col_then_sub`)
- `tools/benchmarks/bench_solve_periodic_columnar_pipeline_sub_then_col.py` (`order=sub_then_col`)

## 3) Run controls (hardcoded, edit in file top section)
For `bench_solve_periodic_columnar_pipeline.py`:
- `PIPELINE_RUN_MODE`
- `FORCE_RERUN_PROVEN`
- `KEY_SEEDS_OVERRIDE`
- `TIERS_REGEX_OVERRIDE`
- `AVOID_REPEAT_FAIL`
- `FAILED_RETRY_SEED_DELTA`

Defaults are set for community reproducibility:
- autoskip proven: on
- rerun proven: off
- no tier/seed override (profile-defined matrix runs as-is)

## 4) Execute
```powershell
python tools/benchmarks/bench_solve_periodic_columnar_pipeline.py
```

## 5) Share results
Share the run folder under:
- `output/tools/benchmarks/<timestamp>__bench_solve_pipeline__<gitshort>/`

Minimum files to share:
- `summary.json`
- `instances.csv`
- `stages.csv`

Optional (for deep triage):
- `tools/benchmarks/solve_proof/proven_solve_pipeline_log.csv` append lines generated by your run

## 6) Contributor rule
If you are running a benchmark sweep, do not tune solver constants mid-sweep.
Start a new run after any config change so rows remain analytically clean.

# Periodic Substitution + Transposition Benchmarks

This package is the harmonized home for periodic substitution/transposition benchmark runners.

## Flavors

- `no_wli/`
- `col_then_sub/`
- `sub_then_col/`

## Shared code

- `common/` for reusable benchmark infrastructure (paths, reports, artifacts, logging, telemetry projections).
- `config/` for typed benchmark profile/config definitions.

## Output policy

All outputs are written under `output/tools/benchmarks/` and mirror runner structure:

- `output/tools/benchmarks/periodic_sub_trans/no_wli/...`
- `output/tools/benchmarks/periodic_sub_trans/col_then_sub/...`
- `output/tools/benchmarks/periodic_sub_trans/sub_then_col/...`

## Legacy migration

To copy older run history into this layout (non-destructive), run:

- `C:\Python\Python311\python.exe tools/benchmarks/periodic_sub_trans/common/migrate_legacy_outputs.py`

A manifest is written to:

- `output/tools/benchmarks/periodic_sub_trans/legacy_import_manifest.json`

## Community integration shape

Recommended per-contributor bundle format:

- one run directory per benchmark run
- include `run_config.json`
- include `final_instances/` outputs
- include any stage/top-k artifacts generated by the runner

These bundles can be copied into `output/tools/benchmarks/periodic_sub_trans/<flavor>/community_import/<contributor_id>/...`
and then aggregated by a shared campaign summarizer.

Import helper:

- `C:\Python\Python311\python.exe tools/benchmarks/periodic_sub_trans/common/import_community_bundle.py --source <bundle_dir> --flavor no_wli --contributor <id>`

# Tools Folder

Repository tooling lives here.

## Main areas

- `tools/benchmarks/` benchmark runners and benchmark data management.
- `tools/docs_lint/` documentation linting helpers.
- `tools/repo_tidy/` cleanup and repo maintenance helpers.

## Benchmark home

Periodic substitution/transposition benchmark flavors are under:

- `tools/benchmarks/periodic_sub_trans/no_wli/`
- `tools/benchmarks/periodic_sub_trans/col_then_sub/`
- `tools/benchmarks/periodic_sub_trans/sub_then_col/`
